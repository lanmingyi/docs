# View Model

## MultipleSelectViewModel

多选实体视图模型。

```typescript
import { MultipleSelectViewModel } from '@simple/cesium'
```

用于管理 Viewer 上被选中的多个实体集合，支持高亮、取消选中等操作。

## SelectedPrimitiveModel

选中 Primitive 的视图模型。

```typescript
import { SelectedPrimitiveModel } from '@simple/cesium'
```

管理与高亮当前选中的 Primitive 对象。

# 后台管理系统

后台管理系统面向平台运营及审核人员，提供任务管理、任务订单审核、提现审核、移动端用户管理等功能，登录后台后可通过左侧菜单栏进入各功能模块。

## 一、任务管理

"任务管理"是后台管理系统的核心菜单，左侧子菜单依次为：平台管理、任务列表、视频库管理、任务订单、任务凭据、消息通知、银行卡管理、提现管理、余额变动记录、移动用户管理，覆盖任务配置、订单审核、资金审核与用户管理的完整流程。

### 1.1 平台管理

在"任务管理"—"平台管理"页面，可按平台名称搜索，查看平台类型ID、平台名称（如抖音、小红书、公众号、哔哩哔哩）、平台图标、启用/禁用状态及备注，支持新增、修改、删除平台，用于维护任务可发布的来源平台。

<img src="/images/task-platform/29.png" alt="平台管理页面" style="width:80%;" />

### 1.2 任务列表

在"任务管理"—"任务列表"页面，可按平台类别、任务名称搜索，查看并维护各平台下的具体任务模板，包括任务图标、平台图标、基础任务说明、额外奖励任务、平台说明、任务奖励金额、任务开始/截至时间及投放状态，支持新增、修改、删除与导出。

<img src="/images/task-platform/30.png" alt="任务列表页面" style="width:80%;" />

### 1.3 视频库管理

在"任务管理"—"视频库管理"页面，可按关联任务ID、视频地址搜索，查看各任务关联的教学/素材视频，包括视频名称、视频地址、预览播放入口、视频状态（未下载/已下载），支持新增、修改、删除与导出。

<img src="/images/task-platform/31.png" alt="视频库管理页面" style="width:80%;" />

### 1.4 任务订单

在"任务管理"—"任务订单"页面，可按任务ID、用户平台ID、提交时间、审核时间、奖励到账时间、订单状态等条件搜索任务订单，查看任务凭据，并对"任务已提交""系统处理中"等状态的订单执行"通过"或"驳回"操作；订单状态包括审核已通过、驳回等，支持分页浏览与导出。

<img src="/images/task-platform/32.png" alt="任务订单管理页面" style="width:80%;" />

### 1.5 任务凭据

在"任务管理"—"任务凭据"页面，可按任务订单ID搜索，以缩略图形式查看用户提交的任务凭据（如任务截图证明），并展示对应的任务订单ID、三方平台用户ID，支持新增、修改、删除与导出。

<img src="/images/task-platform/33.png" alt="任务凭据页面" style="width:80%;" />

### 1.6 任务审核（移动端提交后台侧）

用户在移动端提交任务后，管理员在"任务订单"菜单中查看任务凭据，点击"通过""驳回"按钮完成任务审核；审核结果会同步生成消息通知推送给对应用户，用户可在移动端"已通过""已驳回"分类中查看结果。

### 1.7 消息通知（后台）

在"任务管理"—"消息通知"页面，可按标题、外部订单ID搜索，查看系统自动生成的通知记录，包括通知状态（未读/已读/删除）、类型（审核消息/财务通知/重要通知）、通知内容及关联外部订单ID，支持新增、修改、删除与导出，用于核对推送给移动端用户的各类通知。

<img src="/images/task-platform/37.png" alt="消息通知（后台）页面" style="width:80%;" />

### 1.8 银行卡管理

在"任务管理"—"银行卡管理"页面，可按用户ID、真实姓名、身份证号、银行卡号、银行卡名称、预留手机号等条件搜索，查看用户绑定的银行卡信息，支持新增、修改、删除与导出。

<img src="/images/task-platform/38.png" alt="银行卡管理页面" style="width:80%;" />

### 1.9 提现管理

在"任务管理"—"提现管理"页面，可按订单号、用户ID、提现金额、提现状态、提现类型等条件搜索提现订单，查看提现状态（已打款、审核拒绝、待审核）、申请时间、处理时间、操作人等信息，对待审核订单执行"通过并打款"或"驳回"操作，支持导出提现记录。

<img src="/images/task-platform/39.png" alt="提现管理页面" style="width:80%;" />

### 1.10 余额变动记录

在"任务管理"—"余额变动记录"页面，可按用户类型、变动金额、变动前/后余额、变动时间等条件搜索，查看每一笔账户余额变动的详情及类型（如任务奖励、提现打款等），支持新增、修改、删除与导出，便于核对用户资金流水。

<img src="/images/task-platform/40.png" alt="余额变动记录页面" style="width:80%;" />

### 1.11 移动用户管理

在"任务管理"—"移动用户管理"页面，可按用户昵称、手机号搜索移动端用户，查看用户ID、昵称、头像、手机号、真实姓名、支付宝账号、支付宝手机、邀请码、key字符码等信息，支持新增、修改、删除用户，支持生成key字符码及查看关联银行卡，并支持导出用户列表。

<img src="/images/task-platform/41.png" alt="移动用户管理页面" style="width:80%;" />

## 二、其他模块

后台管理系统另设有"系统管理""系统监控""系统工具"等模块，用于账号权限配置、系统运行监控与运维支持。

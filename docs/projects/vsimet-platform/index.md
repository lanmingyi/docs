# 虚拟仿真实验教学平台

> Virtual Simulation Experiment Teaching Course Unified Management Platform

## 项目简介

面向高校虚拟仿真实验教学场景的综合管理软件，由三部分组成：

- **学生端（Web）** — 供学生浏览课程、在线开展仿真实验并查看个人学习数据
- **管理端（Web）** — 供教务及运维人员维护课程、查看数据分析并管理智慧教室
- **智慧教室H5（移动端）** — 供师生及运维人员在移动端完成教室导航、在线课表查询、在线报修与巡检任务处理

## 系统架构

```
学生端（Web）          管理端（Web）         智慧教室H5（移动端）
     │                     │                       │
     └────────────┬────────┴───────────┬───────────┘
                  │                    │
            ┌─────┴─────┐        ┌────┴────┐
            │  业务服务   │        │ 消息推送  │
            └─────┬─────┘        └─────────┘
                  │
            ┌─────┴─────┐
            │  MySQL + Redis │
            └───────────┘
```

## 核心模块

| 端 | 模块 | 功能 |
|---|---|---|
| 学生端 | 课程中心 | 课程浏览、筛选、详情查看 |
| 学生端 | 仿真实验 | 实验操作、数据记录 |
| 学生端 | 个人中心 | 学习数据统计、报告导出 |
| 管理端 | 课程管理 | 课程上下架、信息维护 |
| 管理端 | 数据分析 | 多维度统计、图表展示 |
| 管理端 | 智慧教室 | 建筑/设备/报修/工单管理 |
| 移动端 | 教室导航 | 3D楼层导览、教室VR |
| 移动端 | 在线服务 | 课表查询、报修、状态查询 |

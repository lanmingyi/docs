# 智慧教室H5（移动端）操作手册

智慧教室场景下，除面向管理员的 Web 管理端外，另配套一款面向师生与运维人员的移动端小程序，提供教室导航、在线课表、在线报修、教室状态查询、通知公告与个人报修/巡检任务处理等功能，与 Web 管理端的建筑管理、设备管理、报修事件与工单模块协同工作。

## 一、登录与注册

打开智慧教室小程序，支持"普通登录"与"NETID 登录"（统一身份认证）两种登录方式；新用户可点击"注册"，填写账号、姓名、密码、工号/学号、所属单位、手机号及短信验证码完成注册。

## 二、首页与服务中心

登录成功后进入首页，核心入口包括"3D导航""在线课表""在线报修""扫一扫""教室状态""通知公告""资料下载"；底部"服务中心"标签页则按"3D导航""教室状态""公共服务""运维管理"分组，方便师生和运维人员快速定位功能。

## 三、教室导航与教室VR

点击"3D导航"，按"校区→教学楼→楼层→教室"逐级筛选，以3D楼层示意图查看教室分布；选定教室后可进入"教室VR"全景视图，查看教室名称、编码、类型与地址等基础信息。

## 四、在线课表

点击"在线课表"，以周课表形式展示各教室、各时段的课程安排（课程名称、教室、任课教师）；点击右上角"筛选"，可按学期/学年、教室、课程、日期、教师、学生等条件查询，并可选择按周或按日查看。

## 五、在线报修

点击"在线报修"，填写校区、报修地址、报修类别、报修类型、联系方式及问题描述，可上传最多5份图片或 office 格式附件（单份不超过100M），点击"提交"完成报修申请。提交后的报修单会同步至 Web 管理端的"报修事件管理"模块。

<img src="/images/vsimet-platform/31.png" alt="在线报修——提交表单" style="width:50%;" />

## 六、教室状态查询

点击"教室状态"，按"使用中/空闲/故障"分类统计并列出各教室的当前状态，支持按校区、楼栋筛选，帮助师生快速找到可用教室。

## 八、个人中心（我的报修/我的巡检）

个人中心展示用户手机号、所属院系等基本信息，并提供"我的报修""我的巡检"两个入口。

<img src="/images/vsimet-platform/38.png" alt="个人中心首页" style="width:50%;" />

"我的报修"展示用户提交的报修记录及处理状态，支持按标题搜索，点击记录可查看报修详情。
